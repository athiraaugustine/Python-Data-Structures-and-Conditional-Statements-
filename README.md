# Python-Data-Structures-and-Conditional-Statements-

## Overview
This projects covers Python data structures , their basic operations and conditional statements using simple practical examples.

## Topics and Methods Used
- - **LISTS:** Created age and name list and used append(),insert(),remove(),pop(),and extend() for list manipulation ; sort() and reverse() for ordering; max(),min(),and sum() for aggregation; indexing and slicing for accessing elements.
- - **DICTIONARIES:** Created a student dictionary . Used keys(), values(), and items() for data retrieval, and get() and update() for accessing and modifying key-value pairs
  - **SETS:** Created set and used union() and intersection() for set operations and tested element modification.
  - **Conditional Statements:** Used if, elif and else for condition checking and decision making.

  ## Tools & Technology
  - Python
  - Jupyter Notebook

  ## Conlusion
  This project demonstrates the use of Python data structures, their methods and conditional statements through practical coding examples.
